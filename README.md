# Quarda for macOS

Нативный таск-менеджер на SwiftUI в виде матрицы Эйзенхауэра.

## Возможности

- четыре квадранта по важности и срочности;
- добавление задач в выбранный квадрант;
- необязательное подробное описание при создании и редактировании;
- перетаскивание задач внутри квадрантов и между ними;
- отметка задач выполненными и удаление;
- отдельный список выполненных задач с возможностью вернуть их в работу;
- локальное хранение через SwiftData.

## Где хранятся задачи

Данные находятся отдельно от приложения:

```text
~/Library/Application Support/ru.msidukov.Quarda/tasks.store
```

Поэтому задачи сохраняются после закрытия приложения, перезагрузки macOS и
переустановки `.app`. Установщик заменяет только приложение в `/Applications`
и не удаляет пользовательские данные.

## Установка одной командой

Из корня проекта выполните:

```shell
./install.sh
```

Скрипт соберёт Release-версию, установит `Quarda.app` в
`/Applications` и сразу запустит её. При необходимости macOS запросит пароль
администратора.

## Запуск из Xcode

Откройте `Quarda.xcodeproj` в Xcode и запустите схему
`Quarda` на `My Mac`. Требуется macOS 14 или новее.

Проверка из терминала:

```shell
xcodebuild -project Quarda.xcodeproj \
  -scheme Quarda \
  -destination 'platform=macOS' \
  -derivedDataPath ./DerivedData \
  CODE_SIGNING_ALLOWED=NO test
```
